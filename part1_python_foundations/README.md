\# Part 1 – Python Foundations



\## Objective



Analyze the Trending YouTube Video Statistics dataset using core Python and Pandas.



\## Dataset



This part uses trending YouTube video data from:

\- United States (US)

\- Great Britain (GB)

\- India (IN)



The dataset also includes category information.



\## Topics Covered



\- Loading CSV files with Pandas

\- Converting DataFrames to dictionaries

\- Data cleaning

\- Lists, dictionaries, tuples and sets

\- Nested dictionaries

\- Slicing

\- Variable scope

\- for loops and while loops

\- range()

\- break and continue

\- Functions

\- Video title feature extraction

\- Rule-based video classification



\## Tools



\- Python

\- Pandas

\- Google Colab
